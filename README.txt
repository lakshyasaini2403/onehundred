# Lakshya Habit Tracker

## Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Optional: add your own photo named `profile.jpg`.
3. Open `index.html` in Chrome/Edge.

## What it includes
- Animated home → tracker transition from the top-right.
- Personal profile/photo area.
- Habit rows and Day 1 onward through Dec 31, 2027.
- Clickable cells: Done → Missed → Blank.
- Numeric habits use a small input prompt.
- Automatic daily score, overall completion, tracked days, and best day.
- Data persists in browser localStorage.

The tracker starts on September 22, 2026 and runs through December 31, 2027.
